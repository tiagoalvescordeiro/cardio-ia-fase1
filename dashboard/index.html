O modelo neuromórfico (Leaky Integrate-and-Fire - LIF) simula um neurônio que acumula estímulos até disparar um alerta (spike). É muito mais leve computacionalmente do que a Regressão Logística, ideal para dispositivos Edge (como o ESP32).

# Função Neurônio LIF (Leaky Integrate-and-Fire)
def run_lif_model(input_series, threshold, decay_rate):
    potential = 0.0
    spikes = []
    
    for stimulus in input_series:
        # Estímulo baseado na variação do BPM
        stim_val = max(0, stimulus - 75)
        
        # Acúmulo com vazamento (Leak)
        potential = (potential * decay_rate) + (stim_val * 0.1)
        
        if potential >= threshold:
            spikes.append(1) # Spike!
            potential = 0.0   # Reset
        else:
            spikes.append(0)
            
    return spikes

Glossário de Parâmetros

Potencial de Membrana

O nível de carga acumulada pelo neurônio artificial. Representa o estado atual de alerta do sistema.

Limiar (Threshold)

O valor crítico (5.00). Ao ser atingido, a IA confirma uma anomalia real e dispara o alerta (Spike).

Vazamento (Leak)

A taxa de decaimento (0.8). Permite que a IA "esqueça" picos momentâneos e ruídos que não são riscos contínuos.

Estímulo (Stimulus)

A entrada de dados. No CardioIA, é a diferença entre o BPM atual e a zona de repouso (75 BPM).
