# Firmware (ESP32)

O *sketch* principal da **Fase 3 (IoT)** encontra-se em **`wokwi/sketch.ino`**, com **`wokwi/diagram.json`** para simulação no **Wokwi**.

O projeto inclui **URL do Wokwi** e **código comentado**; manter o `.ino` junto do diagrama facilita importação e revisão.

Opcionalmente, após validação no simulador, pode-se duplicar o `.ino` nesta pasta (ex.: `cardioia_fase3.ino`) para cópia local, sem alterar a referência oficial em `wokwi/`.
